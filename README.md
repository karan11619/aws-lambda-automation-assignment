# AWS Automation with Lambda & Boto3

A collection of hands-on AWS automation projects built using **AWS Lambda**, **Python (Boto3)**, and various AWS services. These projects demonstrate event-driven serverless automation for common cloud administration tasks.

- AWS Account
- Python 3.12
- Boto3
- IAM permissions to create AWS resources
- AWS Cost Explorer enabled (Assignment 4)
- Confirmed SNS email subscription (Assignment 4)
